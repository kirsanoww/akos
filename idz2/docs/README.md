# Материалы отчёта

- `main.pdf` - готовый отчёт
- `main.tex` - титульный лист и подключение текста
- `header.sty` - оформление из первого ИДЗ
- `report.tex` - содержание отчёта
- `PROMPTS.md` - примеры запросов для разработки и разбора решения
- `DEBUGGING.md` - проведённые проверки, исправления и ограничения

Сборка из этой папки: `latexmk -pdf main.tex`.
