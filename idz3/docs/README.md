# Документы ИДЗ 3

- `main.pdf` — краткий отчёт
- `main.tex` — титульный лист и подключение текста
- `header.sty` — оформление на основе hse-se-lecture-notes
- `report.tex` — содержание отчёта
- `PROMPTS.md` — запросы к ИИ для разработки и разбора ИДЗ 3
- `DEBUGGING.md` — результаты проверок и исправления
- `test-results.txt` — фактический вывод тестов и демонстраций
- `TEMPLATE_LICENSE` — лицензия исходного шаблона

Сборка: `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` из этой папки.
