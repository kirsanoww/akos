# Документы ИДЗ4

- `main.pdf` - отчёт
- `main.tex`, `report.tex`, `header.sty` - LaTeX-исходники и оформление
- `PROTOCOL.md` - роли, сообщения, восстановление, ограничения
- `DEBUGGING.md` - выполненные проверки и исправления
- `test-results.txt` - вывод проверок
- `PROMPTS.md` - запросы к ИИ при подготовке работы
- `TEMPLATE_LICENSE` - лицензия шаблона

Сборка: `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` из этой папки.

Приложенный PDF собран установленным MacTeX и проверен визуально: 3 страницы,
без ошибок и переполнений в журнале сборки. Встроенная сборка предпросмотра
в приложении завершилась ошибкой; для просмотра можно открыть готовый `main.pdf`.
